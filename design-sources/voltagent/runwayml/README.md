# RunwayML design source

Source: user-supplied VoltAgent awesome-design-md archive, `design-md/runwayml/DESIGN.md`.

This is an independently implemented design-system study, **not the Runway website's source code**. The demo uses an original fictional identity and third-party demo photography; no Runway trademarks, product claims, or proprietary fonts are bundled. Rendered templates are static, sandbox-friendly HTML with CSS motion and section navigation.

The default `runwayml` gallery demo does **not** adapt to a resume/business example. Customer-provided text and approved uploads are used when generating real orders.
