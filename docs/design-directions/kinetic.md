# Kinetic Club — Original AWE Concepts DESIGN.md

**Template:** kinetic. **Visual intention:** skewed athletic type. **Research:** [Nike on Refero Styles](https://styles.refero.design/style/d7ace114-0548-41f5-a2ff-2afbf32be94d).

This is an independently authored design brief, not Refero's source document.

## Signature composition
Use a distinct skewed athletic type layout, illustrated through original CSS geometry, composition, a deliberate first-fold typography hierarchy, and art-directed service/work sections. Never reproduce the reference brand, screenshot or proprietary assets.

## Content contract
Customer-editable copy, project cards, links, photos, services, testimonials, section visibility and color themes must render accurately. Include a clear fictional-demo label for sample data and no invented client claims.

## Engineering requirements
Mobile readability at 320, 375 and 768px; tested keyboard links; no horizontal overflow; content escape and HTTPS validation; script-free static pages; reduced-motion support; branded preview consistency. Retain AWE Concepts' own identity in the shopping interface.
