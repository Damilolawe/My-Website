# Awe Concepts · Template differentiation

The four supplied references set the **quality** threshold: hospitality photography
and editorial sequencing; a technical product visualization; expressive creative
objects and typography; and restrained fashion art direction. They are not four
skins to distribute across twenty sites. All screenshots are reference material,
not assets to copy into production.

This matrix is the creative brief for completing the collection. The four
reference-led signature chapters in PR #69 are a **first batch**, not acceptance
of the entire collection. Each remaining design needs real implementation,
mobile composition, imagery or original graphics, a working interaction, and
side-by-side visual review before its row can be marked complete.

## Acceptance gate for each row

1. The mobile and desktop first folds have visibly different composition from
   other templates, not a shared skeleton with a new palette.
2. All links and controls have an actual destination or response. Demo-only
   interactions are labeled; no fake bookings, messages or payments.
3. Real customer content is escaped. Fictional sample images never leak into
   customer HTML; approved customer images replace sample imagery.
4. The generated full page and theater iframe both render without broken
   images, clipping, horizontal overflow, console errors or dead anchors.
5. The public and Supabase renderer copies match before their releases are
   coordinated. No production release is inferred from passing source tests.
